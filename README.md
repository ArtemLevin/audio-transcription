# Whisper Lesson Transcriber

Скрипт для транскрибации аудиозаписей занятий через Whisper с последующей предобработкой текста для нейросетевого анализа.

Скрипт решает две задачи:

1. Преобразует аудиофайл занятия в текст, SRT-субтитры и JSON-сегменты.
2. Готовит транскрипт к дальнейшей обработке нейросетью: очищает технический мусор, сворачивает повторы, выделяет важные сигналы ученика и разбивает текст на чанки.

---
a# Whisper Lesson Transcriber + Ollama

Скрипт для транскрибации аудиозаписей учебных занятий через Whisper с последующей очисткой транскрипта и опциональной обработкой локальной нейросетью через Ollama.

Скрипт предназначен для подготовки учебных материалов на основе записей занятий:

* учебных протоколов;
* конспектов;
* пособий;
* чек-листов;
* домашних заданий;
* карточек ошибок;
* материалов для повторения.

---

## 1. Что делает скрипт

Скрипт выполняет полный цикл обработки аудиозаписи занятия:

```text
Аудиофайл
↓
Подготовка аудио через ffmpeg
↓
Транскрибация через Whisper
↓
Сохранение сырого транскрипта
↓
Техническая очистка текста
↓
Поиск важных сигналов ученика
↓
Разбиение на чанки для LLM
↓
Опциональная обработка через Ollama
↓
Итоговый учебный протокол занятия
```

---

## 2. Основные возможности

Скрипт умеет:

* обрабатывать аудиофайлы из указанной папки;
* искать аудиофайлы во вложенных папках;
* поддерживать форматы `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`, `.aac`, `.wma`;
* приводить аудио к стабильному формату WAV mono 16 kHz;
* транскрибировать аудио через Whisper;
* сохранять сырой TXT;
* сохранять SRT-субтитры;
* сохранять транскрипт с таймкодами;
* сохранять JSON с сегментами Whisper;
* очищать транскрипт в разных режимах;
* удалять технический мусор автосубтитров;
* сворачивать длинные повторы;
* находить важные сигналы ученика;
* разбивать очищенный транскрипт на чанки;
* создавать prompt-файл для дальнейшей LLM-обработки;
* обрабатывать чанки локальной моделью через Ollama;
* собирать итоговый учебный протокол занятия;
* сохранять технические отчёты и манифест обработки.

## 3. Требования

### Python

Рекомендуется Python 3.10 или новее.

Проверить версию:

```bash
python --version
```

---

### FFmpeg

Для работы нужен `ffmpeg` и `ffprobe`.

Проверка:

```bash
ffmpeg -version
ffprobe -version
```

Если команды не находятся, значит `ffmpeg` не установлен или не добавлен в `PATH`.

---

### Whisper

Скрипт использует пакет `openai-whisper`.

Установка:

```bash
pip install openai-whisper
```

---

### Ollama

Ollama нужна только при запуске с флагом `--ollama`.

Без этого флага скрипт работает только как транскрибатор и очиститель текста.

Проверить Ollama:

```bash
ollama --version
```

Проверить доступные модели:

```bash
ollama list
```

Скачать модель:

```bash
ollama pull qwen2.5:7b
```

## 4. Установка

Создайте папку проекта:

```bash
mkdir lesson-transcriber
cd lesson-transcriber
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте окружение.

### Windows PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

### Windows CMD

```cmd
venv\Scripts\activate.bat
```

### Linux / macOS

```bash
source venv/bin/activate
```

Обновите `pip`:

```bash
python -m pip install -U pip
```

Установите Whisper:

```bash
pip install openai-whisper
```

При необходимости установите PyTorch отдельно, особенно если планируется использовать GPU.

## 7. Быстрый запуск с Ollama

Сначала скачайте локальную модель:

```powershell
ollama pull qwen2.5:7b
```

Затем запустите скрипт:

```powershell
python transcribe_lessons.py "C:\Users\Artem\AudioLessons" --model small --language ru --clean-mode balanced --ollama --ollama-model qwen2.5:7b
```

В этом режиме скрипт:

1. Распознаёт аудио через Whisper.
2. Очищает транскрипт.
3. Делит текст на чанки.
4. Отправляет каждый чанк в Ollama.
5. Создаёт протоколы отдельных фрагментов.
6. Пытается собрать итоговый учебный протокол занятия.

| -------- | -----------: | -----------: | --------------------------- |
| `tiny`   | очень быстро |       низкое | тесты, слабый ПК            |

## 10. Режимы очистки транскрипта

Параметр:

```bash
--clean-mode
```

Доступные значения:

```text
conservative
balanced
aggressive
```

---

### `conservative`

Бережная очистка.

```bash
python transcribe_lessons.py audio --clean-mode conservative
```

Удаляет только очевидный мусор и очень длинные повторы.

Подходит для:

* анализа ошибок ученика;
* спорных фрагментов;
* проверки качества объяснения;
* ситуаций, когда нельзя потерять детали.

---

### `balanced`

Рабочий режим по умолчанию.

```bash
python transcribe_lessons.py audio --clean-mode balanced
```

Удаляет явный мусор, но сохраняет:

* вопросы ученика;
* затруднения;
* ошибки;
* методические акценты;
* важные объяснения;
* ключевые фразы занятия.

Рекомендуемый режим для повседневной работы.

---

### `aggressive`

Сильная очистка.

```bash
python transcribe_lessons.py audio --clean-mode aggressive
```

Удаляет больше разговорной обвязки и повторов.

Подходит, если в транскрипте много:

* ASR-мусора;
* повторов;
* случайных фраз;
* субтитровых вставок;
* бессмысленных фрагментов.

Использовать осторожно: часть устной речи может быть удалена.

## 12. Описание основных выходных файлов

### `00_raw_whisper.txt`

Сырой текст, полученный от Whisper.

Эту версию лучше не редактировать вручную. Она нужна как исходник.

---

### `00_raw_timestamped.txt`

Транскрипт с таймкодами.

Пример:

```text
[00:01:15 — 00:01:23] Давайте запишем условие задачи.
[00:01:23 — 00:01:40] Здесь важно понять, что четверть объёма соответствует четверти высоты.
```

Полезно для поиска нужного места в аудио.

---

### `00_raw_segments.srt`

SRT-субтитры.

Можно использовать:

* в видеоредакторах;
* в медиаплеерах;
* для проверки качества распознавания;
* для ручной сверки с аудио.

---

### `00_raw_segments.json`

JSON с сегментами Whisper.

Содержит:

* начало сегмента;
* конец сегмента;
* текст;
* `avg_logprob`;
* `no_speech_prob`;
* `compression_ratio`.

---

### `01_normalized.txt`

Текст после базовой нормализации:

* исправлены пробелы;
* нормализованы переносы строк;
* убраны лишние технические символы.

---

### `02_clean_balanced.txt`

Основной очищенный транскрипт.

Название зависит от режима очистки:

```text
02_clean_conservative.txt
02_clean_balanced.txt
02_clean_aggressive.txt
```

Обычно дальше используется именно этот файл.

---

### `03_llm_chunks/`

Папка с кусками очищенного транскрипта.

Используется, если занятие длинное и весь текст не помещается в один запрос к LLM.

---

### `04_llm_prompt.md`

Готовый промпт для дальнейшей обработки нейросетью.

Можно использовать вручную: открыть файл, скопировать содержимое и передать модели.

---

### `important_student_signals.json`

Автоматически найденные важные сигналы ученика.

Например:

```json
[
  {
    "signal": "не понимаю",
    "position": 15420,
    "snippet": "..."
  }
]
```

Сюда попадают фразы вроде:

```text
не понимаю
не поняла
можно ещё раз
почему
я зависла
не получается
у меня другой ответ
не сходится
```

---

### `cleaning_report.md`

Краткий отчёт об очистке:

* какой файл обработан;
* какой режим очистки использован;
* размер сырого текста;
* размер очищенного текста;
* сколько создано чанков;
* какие сигналы ученика найдены;
* что делать дальше.

---

### `manifest.json`

Технический манифест обработки.

Содержит:

* путь к исходному аудио;
* длительность;
* параметры Whisper;
* параметры очистки;
* параметры Ollama;
* список созданных файлов.

---

## 13. Файлы Ollama-обработки

Создаются только при запуске с флагом:

```bash
--ollama
```

---

### `05_ollama_chunk_protocols/`

Папка с протоколами отдельных чанков.

Пример:

```text
chunk_001_protocol.md
chunk_002_protocol.md
chunk_003_protocol.md
```

Каждый файл содержит методический разбор одного фрагмента занятия.

---

### `chunk_001_ollama_response.json`

Сырой JSON-ответ Ollama для конкретного чанка.

Нужен для отладки.

---

### `06_ollama_final_protocol.md`

Итоговый учебный протокол занятия.

Обычно это главный результат Ollama-обработки.

В нём должны быть:

* краткая сводка занятия;
* основные темы;
* хронология;
* разобранные задачи;
* ключевые формулы;
* основные приёмы;
* ошибки и затруднения ученика;
* материал для пособия;
* неясные места.

---

### `06_ollama_final_prompt.md`

Prompt, который был отправлен в Ollama для сборки итогового протокола.

Полезно для отладки и повторной обработки.

---

### `06_ollama_final_response.json`

Сырой ответ Ollama при создании итогового протокола.

---

### `ollama_report.json`

Технический отчёт Ollama-этапа:

* модель;
* URL Ollama;
* количество чанков;
* пути к протоколам чанков;
* статус финальной сборки.

```bash
python transcribe_lessons.py audio --ollama --ollama-model qwen2.5:7b
```

---

### Полный рекомендуемый запуск

```bash
python transcribe_lessons.py audio ^
  --model small ^
  --language ru ^
  --clean-mode balanced ^
  --chunk-size 5000 ^
  --chunk-overlap 600 ^
  --ollama ^
  --ollama-model qwen2.5:7b ^
  --ollama-temperature 0.1 ^
  --ollama-num-ctx 8192
```

Для PowerShell одной строкой:

```powershell
python transcribe_lessons.py "C:\Users\Artem\AudioLessons" --model small --language ru --clean-mode balanced --chunk-size 5000 --chunk-overlap 600 --ollama --ollama-model qwen2.5:7b --ollama-temperature 0.1 --ollama-num-ctx 8192
```

---

### Использовать другую модель Ollama

```bash
python transcribe_lessons.py audio --ollama --ollama-model llama3.1:8b
```

---

### Только обработать чанки, без финальной сборки

```bash
python transcribe_lessons.py audio --ollama --no-ollama-final-synthesis
```

Полезно для длинных занятий, когда итоговый prompt получается слишком большим.

---

### Увеличить контекст Ollama

```bash
python transcribe_lessons.py audio --ollama --ollama-num-ctx 16384
```

---

### Увеличить лимит генерации

```bash
python transcribe_lessons.py audio --ollama --ollama-num-predict 5000
```

---

### Увеличить лимит финального prompt

```bash
python transcribe_lessons.py audio --ollama --ollama-final-max-chars 80000
```

## 16. Параметры командной строки

### Основные параметры

| Параметр          | Значение по умолчанию | Описание                         |
| ----------------- | --------------------: | -------------------------------- |
| `input_dir`       |          обязательный | Папка с аудиофайлами             |
| `--model`         |               `small` | Модель Whisper                   |
| `--language`      |                  `ru` | Язык речи                        |
| `--beam-size`     |                   `5` | Ширина beam search               |
| `--clean-mode`    |            `balanced` | Режим очистки                    |
| `--chunk-size`    |                `6000` | Размер чанка для LLM             |
| `--chunk-overlap` |                 `500` | Перекрытие между чанками         |
| `--recursive`     |             выключено | Искать файлы во вложенных папках |
| `--verbose`       |             выключено | Подробный лог                    |

---

### Параметры Whisper

| Параметр                       | Значение по умолчанию | Описание                                     |
| ------------------------------ | --------------------: | -------------------------------------------- |
| `--initial-prompt`             |        учебный prompt | Подсказка Whisper по тематике занятия        |
| `--condition-on-previous-text` |             выключено | Учитывать предыдущий текст при распознавании |
| `--keep-prepared-wav`          |             выключено | Сохранять WAV после подготовки аудио         |

---

### Параметры Ollama

| Параметр                      |    Значение по умолчанию | Описание                              |
| ----------------------------- | -----------------------: | ------------------------------------- |
| `--ollama`                    |                выключено | Включить обработку через Ollama       |
| `--ollama-url`                | `http://localhost:11434` | URL Ollama API                        |
| `--ollama-model`              |             `qwen2.5:7b` | Локальная модель Ollama               |
| `--ollama-timeout`            |                    `900` | Таймаут запроса в секундах            |
| `--ollama-temperature`        |                    `0.1` | Температура генерации                 |
| `--ollama-num-ctx`            |                   `8192` | Размер контекста                      |
| `--ollama-num-predict`        |                   `3000` | Максимум токенов ответа               |
| `--ollama-keep-alive`         |                    `10m` | Сколько держать модель загруженной    |
| `--no-ollama-final-synthesis` |                выключено | Не собирать итоговый протокол         |
| `--ollama-final-max-chars`    |                  `45000` | Максимальный размер финального prompt |

## 21. Важные ограничения

Скрипт не является полноценным математическим проверяющим.

Он не должен автоматически:

* выдумывать условия задач;
* исправлять формулы без проверки;
* гарантировать правильность числовых ответов;
* утверждать, что ученик понял тему;
* делать окончательные выводы об ошибках ученика без контекста.

Особенно осторожно нужно относиться к:

* формулам;
* степеням;
* индексам;
* дробям;
* логарифмам;
* геометрическим обозначениям;
* физическим величинам;
* химическим формулам;
* числовым ответам.

## 24. Назначение проекта

Этот скрипт — основа локальной фабрики учебных материалов:

```text
Запись занятия
↓
Транскрипт
↓
Очищенный учебный текст
↓
Учебный протокол
↓
Персональное пособие
↓
Тренировочные задания
↓
Карточка ошибок
↓
Образовательный плакат
```

Главная идея: не просто получить текст аудиозаписи, а превратить занятие в структурированный учебный материал.

## Возможности

Скрипт умеет:

* обрабатывать аудиофайлы из указанной папки;
* поддерживать форматы `.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`, `.aac`, `.wma`;
* автоматически готовить аудио для Whisper через `ffmpeg`;
* сохранять сырой транскрипт;
* сохранять SRT-субтитры;
* сохранять транскрипт с таймкодами;
* сохранять JSON с сегментами Whisper;
* очищать транскрипт в нескольких режимах;
* находить важные фразы ученика: «не понимаю», «можно ещё раз», «я зависла» и т. д.;
* разбивать очищенный транскрипт на чанки для LLM;
* создавать готовый prompt-файл для дальнейшей методической обработки;
* создавать отчёт об очистке.

## Режимы очистки

Скрипт поддерживает три режима очистки.

### `conservative`

Бережная очистка.

Используйте, если важно сохранить максимум исходной речи.

```bash
python transcribe_lessons.py audio --clean-mode conservative
```

Подходит для:

* анализа ошибок ученика;
* спорных фрагментов;
* проверки качества объяснения;
* ситуаций, где нельзя потерять детали.

---

### `balanced`

Рабочий режим по умолчанию.

```bash
python transcribe_lessons.py audio --clean-mode balanced
```

Подходит для большинства занятий.

Удаляет явный мусор, но сохраняет:

* вопросы ученика;
* затруднения;
* ошибки;
* методические акценты;
* важные объяснения.

---

### `aggressive`

Сильная очистка.

```bash
python transcribe_lessons.py audio --clean-mode aggressive
```

Подходит, если в транскрипте очень много мусора:

* повторов;
* обрывков автосубтитров;
* технических фраз;
* бессмысленных вставок.

Используйте осторожно: этот режим может удалить часть разговорной речи.

## Описание выходных файлов

### `00_raw_whisper.txt`

Сырой текст, который вернул Whisper.

Эту версию лучше не редактировать вручную. Она нужна как исходник.

---

### `00_raw_timestamped.txt`

Транскрипт с таймкодами.

Пример:

```text
[00:01:15 — 00:01:23] Давайте запишем условие задачи.
[00:01:23 — 00:01:40] Здесь важно понять, что четверть объёма соответствует четверти высоты.
```

Полезно для поиска нужного места в аудио.

---

### `00_raw_segments.srt`

SRT-субтитры.

Можно использовать в видеоредакторах, плеерах или для проверки распознавания.

---

### `00_raw_segments.json`

JSON с сегментами Whisper.

Содержит:

* начало сегмента;
* конец сегмента;
* текст;
* служебные метрики Whisper.

---

### `01_normalized.txt`

Текст после базовой нормализации:

* исправлены пробелы;
* нормализованы переносы строк;
* убраны лишние технические символы.

---

### `02_clean_balanced.txt`

Основной очищенный транскрипт.

Название зависит от выбранного режима очистки:

```text
02_clean_conservative.txt
02_clean_balanced.txt
02_clean_aggressive.txt
```

Именно этот файл обычно используется дальше.

---

### `03_llm_chunks/`

Папка с кусками очищенного транскрипта для нейросети.

Используется, если занятие длинное и весь текст не помещается в один запрос.

Пример:

```text
chunk_001.txt
chunk_002.txt
chunk_003.txt
```

---

### `04_llm_prompt.md`

Готовый промпт для дальнейшей обработки нейросетью.

Его можно открыть, скопировать и передать вместе с очищенным транскриптом или чанками.

Задача этого промпта — получить структурированный учебный протокол занятия:

* темы;
* задачи;
* формулы;
* ошибки ученика;
* затруднения;
* методические акценты;
* материал для пособия.

---

### `important_student_signals.json`

Автоматически найденные важные сигналы ученика.

Например:

```json
[
  {
    "signal": "не понимаю",
    "position": 15420,
    "snippet": "..."
  }
]
```

Это помогает быстро найти места, где ученик испытывал затруднение.

---

### `cleaning_report.md`

Краткий отчёт об очистке:

* какой файл обработан;
* какой режим очистки использован;
* размер сырого и очищенного текста;
* сколько создано чанков;
* какие сигналы ученика найдены;
* что делать дальше.

---

### `manifest.json`

Технический файл с параметрами обработки.

Содержит:

* путь к исходному аудио;
* длительность;
* модель Whisper;
* язык;
* параметры очистки;
* список созданных файлов.

Полезен для воспроизводимости.
